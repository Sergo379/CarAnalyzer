# Исследование Auto.ru для первого адаптера

Дата проверки: 22 сентября 2026 года.

Проверенная страница: `https://auto.ru/cars/bmw/5er/used/`.

## Фактический ответ

- Обычный `GET` с браузерным `User-Agent` вернул `200 OK` и серверный HTML объёмом
  около 789 КБ. На этой проверке CAPTCHA и обязательный Playwright не потребовались.
- В выдаче было 41 уникальная ссылка вида `/cars/used/sale/...`.
- Страница содержала три блока `application/ld+json`.
- Основной JSON-LD объект имел тип `Product` с `AggregateOffer`: общее количество
  объявлений и 37 предложений текущей страницы.
- Для каждого JSON-LD предложения доступны как минимум `url`, `price`, `availability`,
  `priceCurrency`, `priceValidUntil` и изображение с названием автомобиля.

## Ограничения структурированных данных

JSON-LD текущей поисковой страницы не содержит полного обязательного набора
`CarListing`: в предложении отсутствуют отдельные поля года, кузова и местоположения.
Идентификатор объявления можно устойчиво извлечь из URL. Остальные поля следует
получать из семантики карточки/страницы объявления и валидировать, а не угадывать.

HTML-классы карточек имеют изменяемые суффиксы (например,
`ListingItemUniversal__...-xxxxx`). Поэтому будущий адаптер не должен полагаться на
полное имя такого CSS-класса. Ссылки объявления и JSON-LD выглядят более устойчивыми
первичными точками входа.

## Рекомендуемый порядок реализации

1. HTTP-запрос поисковой страницы с явными таймаутами и ограниченным числом повторов.
2. Извлечение JSON-LD и ссылок карточек; дедупликация по `source + external_id`.
3. Дополнение обязательных полей из карточки или страницы объявления.
4. Строгая валидация результата через `CarListing`; некорректные карточки не маскировать.
5. Детектировать редирект на авторизацию, CAPTCHA и защитную страницу как отдельные
   состояния, а не возвращать пустую выдачу.
6. Playwright использовать только как browser-assisted fallback, если HTTP-путь
   перестанет давать необходимые данные. CAPTCHA проходит пользователь вручную.

Это исследование фиксирует наблюдаемую структуру на дату проверки, но не является
гарантией стабильности частного HTML/API Auto.ru.
